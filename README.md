# VMimic — Webカメラ1台で動くリアルタイムアバターシステム

2Dや3D（UX）などに興味があり、2026年4月から作成を始めました。

Webカメラ1台で人間の顔と全身の動きをAIが読み取り、3Dアバター（VRM）にリアルタイムで反映させる自作システムです。市販のVTuberソフトと同じ原理を、仕組みから自分で実装しました。

## 使用技術
Unity / C# / MediaPipe（AI姿勢・表情推定）/ UniVRM

## できること
顔（首・まばたき・口の動き）と全身（腕・肩・重心）を同時にトラッキング。ジェスチャー検出やエフェクト演出も実装。

## 工夫した点
2つのAIで1台のカメラを共有する仕組みや、スレッド安全なデータ処理を自作。AIの生データは震えるため、補間処理と信頼度フィルタでなめらかな動きを実現しました。「動かす」より、問題を切り分け原因を特定して解決する過程を大切にしました。
